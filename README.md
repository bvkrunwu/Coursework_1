# 🗂️ Курсовая работа: Приложение для анализа банковских операций

Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.

---

##  Общая Информация о Проекте

Представляем вам комплексный финансовый сервис, объединяющий несколько специализированных модулей для удобного и эффективного управления персональными финансами. Данный проект охватывает широкий спектр задач, от сбора и анализа финансовых данных до автоматизированной подготовки отчетов и оптимизации программ лояльности.

Система построена с учетом современных стандартов разработки программного обеспечения и обеспечивает высокую степень гибкости, масштабируемости и простоты интеграции новых функциональных возможностей.

---

##  Структура Проекта

Комплекс состоит из трёх взаимосвязанных компонентов:

1. **Основное Веб-Приложение**
   - Ядро системы, ответственное за предоставление персонализированной финансовой информации. 
   
2. **Cashback Analyzer Service**
   - Специализированный модуль для анализа эффективности категорий кешбэка.
   
3. **Модуль Reports**
   - Автономный компонент для автоматического формирования и хранения финансовых отчетов.

---

##  Основное Веб-Приложение

Это серверная часть веб-приложения, обеспечивающая взаимодействие с пользователями посредством REST API-интерфейсов. Она предназначена для предоставления персонализированной финансовой информации, включая расходы по картам, курсы валют и цены акций компаний индекса S&P500.

### Основные компоненты:

- **views.py**: Основной модуль, формирующий JSON-ответы для клиентского интерфейса.
- **utils.py**: Вспомогательные функции для работы с данными, взаимодействия с внешними API и выполнения вспомогательных расчетов.

### Использование:

Получение финансовых данных выполняется следующим образом:

```python
from src.views import generate_home_response

response = generate_home_response('2023-10-01 14:30:00')
print(response)
```

### Возможности:

- Динамические приветствия, зависящие от текущего времени суток.
- Подробная финансовая отчётность по картам (расходы, кешбэк).
- Интеграция с внешними API для получения актуальных курсов валют и котировок акций.
- Гибкая настройка отображаемых валют и акций через конфигурационный файл `user_settings.json`.

##  Cashback Analyzer Service

Специализированный модуль, предназначенный для анализа исторических транзакционных данных и расчета оптимального размера кешбэка по разным категориям товаров и услуг.

### Назначение:

Помогает финансовым организациям и банкам выявлять наиболее привлекательные категории для предоставления повышенных бонусных вознаграждений своим клиентам.

### Необходимые библиотеки:

- `json`: обработка данных в формате JSON.
- `datetime`: управление временными метками и расчёт временных диапазонов.
- `logging`: ведение журнала событий и диагностика возможных ошибок.

### Аргументы функции анализа:

| Параметр | Тип данных       | Описание                                 |
|----------|------------------|------------------------------------------|
| `data`   | list of dict     | Транзакционные данные в формате словаря. |
| `year`   | int              | Год для анализа.                         |
| `month`  | int              | Месяц для анализа.                       |

### Возвращаемое значение:

JSON-строка с результатами расчёта потенциального кешбэка по категориям.

### Пример использования:

```python
transactions_data = [...]  # ваши транзакционные данные
result = analyze_cashback_categories(transactions_data, 2023, 10)
print(result)
```

### Пример вывода:

```json
{
  "Продукты питания": 1500.00,
  "Развлечения": 800.00,
  "Транспорт": 1200.00
}
```

### Логирование:

Все ключевые события и возникающие ошибки регистрируются в специальном журнале `services.log`, расположенном в папке `logs`. Это значительно упрощает процесс диагностики и мониторинга работоспособности системы.

##  Модуль Reports

Автономный модуль, ориентированный на автоматизацию процесса подготовки финансовых отчетов и проведение глубокого анализа транзакционных данных.

### Основные возможности:

- Автоматизированная подготовка отчетов с использованием встроенного декоратора.
- Сохранение результатов отчетов в формате JSON.
- Гибкая настройка наименований файлов отчетов.
- Подробный логгинг процессов формирования отчетов.
- Анализ транзакций по категориям с возможностью фильтрации по временным интервалам.

### Использование:

Модуль поддерживает использование специального декоратора `report_writer`, позволяющего автоматически сохранять результаты отчетов в файлы:

```python
from reports import report_writer

@report_writer('custom_report_name.json')
def my_report_function():
    # логика вашей функции
    return data_frame_result
```

Если имя файла не передано, декоратор самостоятельно создает уникальное название файла на основании отметки времени и имени функции.

### Функция `spending_by_category`:

Формирует отчет о расходах по конкретной категории за последние три месяца относительно заданной даты.

```python
from reports import spending_by_category

df_transactions = pd.read_csv('transactions.csv')  # загрузка ваших транзакций
result = spending_by_category(df_transactions, 'Еда', '01.01.2023')
print(result)
```

### Параметры функции:

| Параметр      | Тип данных          | Описание                                              |
|---------------|---------------------|-------------------------------------------------------|
| `transactions`| DataFrame           | Датафрейм Pandas с транзакционными данными.          |
| `category`    | str                 | Категория расходов, по которой строится отчет.       |
| `date`        | Optional[str]       | Опциональная дата начала периода в формате ДД.ММ.ГГГГ.|

### Пример использования:

Простой отчет о расходах на транспорт за последний квартал:

```python
transport_spending = spending_by_category(transactions_dataframe, 'Транспорт')
print(transport_spending)
```
